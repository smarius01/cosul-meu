## Platform
web
## Stack
Static HTML/CSS and browser JavaScript. Selected for the user-confirmed GitHub Pages deployment; no server or paid API. Framework choice delegated implicitly by a request for a small easy application (implementation assumption).
## Users
Romanian-speaking shopper with a WhatsApp screenshot of a shopping list. Phone-first is an implementation assumption.
## Product Purpose
Import a screenshot, read its shopping list, tap items to move them to a basket below. Tap again to undo.
## Capabilities and Constraints
User confirmed GitHub Pages hosting. Screenshot OCR runs locally in a browser worker. Reading can be imperfect: editable review is mandatory. Do not store or upload screenshots. Local list persistence; not shared across devices. Free and no login. Support a pasted/manual list too.
## Evidence on Hand
No real screenshot supplied. OCR QA uses clearly labeled synthetic WhatsApp-style fixtures in light and dark modes.
