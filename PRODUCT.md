## Platform
web
## Stack
Static HTML/CSS and browser JavaScript. Selected for the user-confirmed GitHub Pages deployment; no server or paid API. Framework choice delegated implicitly by a request for a small easy application (implementation assumption).
## Users
Romanian-speaking shopper with a WhatsApp screenshot of a shopping list. Phone-first is an implementation assumption.
## Product Purpose
Paste a screenshot directly into the visible text field like ChatGPT; display it as an attachment and use one Fă lista action. Support text in the same field. Then tap products to move them to the basket below; tap again to undo.
## Capabilities and Constraints
User confirmed GitHub Pages hosting. Screenshot OCR runs locally in a browser worker. Reading can be imperfect: products are immediately editable using their pencil control. The user explicitly requested a ChatGPT-style paste composer, not a separate upload/review wizard. Do not store or upload screenshots. Local list persistence; not shared across devices. Free and no login. Support a pasted/manual list too.
