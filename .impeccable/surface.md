# Shopping surface
Mode: Operate. Precise narrow request: screenshot import, list on top, purchased basket below. No concept tournament or marketing hero.
## Direction contract
THESIS: A shopping checklist, not a dashboard. Import stays secondary once there are products.
OWN-WORLD: Crisp white/neutral surfaces, forest-green action color, system sans, generous full-width touch targets; dark tokens follow system preference.
STORY: Import, verify, shop; tap to move an item to the basket below and tap to return it.
FIRST VIEWPORT: A compact brand line and import affordance; active list occupies the center. Empty view offers one large screenshot action and a quieter manual text option.
FORM: User-pinned two-section list/basket topology, code-led native controls. Dials 3/2/5; task efficiency, not a landing page.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
